## What these results are not

They show that the code does what its tests say. They are **not** an error rate on real attacks: there is no real attack
corpus, so no APCER or BPCER is claimed (`docs/claim-sheet.md`, L1). Tests on synthetic data say so in their names or
their documentation, and are never used as headline results.
